# witchcraft

For more information on what this is and how it came to be, check out [my blog post](https://yev.bar/magic).

## Packages

### mtg

This is the unofficial Magic equivalent to `python-chess`. There's a lot more content down in [its respective folder](https://github.com/yevbar/witchcraft/tree/master/packages/mtg).

### inthearena

Contains work relating to automating interactions with the Arena desktop app on Mac. There's a lot more content in [its respective folder](https://github.com/yevbar/witchcraft/tree/master/packages/inthearena).
